# Submission Checklist

## GitHub repository

- [ ] Upload `index.html`, `styles.css`, and `app.js`.
- [ ] Upload `README.md`.
- [ ] Upload `docs/VIDEO_SCRIPT.md` and `docs/SUBMISSION_CHECKLIST.md`.
- [ ] Add a short repository description: “Live event networking app that helps attendees discover who to meet, why, and when.”
- [ ] Add 3–5 screenshots to the README after you take them.
- [ ] Make the repository public if the submission asks for a public link.

## Video

- [ ] 60–120 seconds, matching the task's requested 1–2 minute demonstration range.
- [ ] Record the full flow: Join → Home → Discover → Match reason → Connect → Organizer.
- [ ] Mention the innovation: ranked, explainable matches + live presence, not a static directory.
- [ ] Show the CSV export briefly.
- [ ] Do not spend more than 10 seconds explaining the code.

## Before submitting

- [ ] Click Reset demo data.
- [ ] Refresh once and enter the demo profile again.
- [ ] Test Connect / Disconnect.
- [ ] Test Check out / Check back in.
- [ ] Test Simulate arrival / departure.
- [ ] Test Export CSV.
- [ ] Open a second tab and verify changes propagate.
- [ ] Confirm the final GitHub URL works in an incognito window.
